# 플레이어 걷기 애니메이션 적용 및 전달 사항

## 에셋 용도 정정

두 FBX 모두 플레이어용인 것으로 확인하여 플레이어에 적용했습니다.
이전에 안내한 **추가 리깅 모델 요청은 필요하지 않습니다.**

- `Assets/FBX/Monster/Animation/CHA A.fbx`: 폴더 이름과 달리 플레이어용 모델입니다. 메시·뼈대·스킨·애니메이션이 모두 포함되어 있습니다.
- `Assets/FBX/Player/Animation/walk A.fbx`: 플레이어 뼈대와 걷기 애니메이션입니다. 이 파일에 메시가 없더라도 위 모델과 연결하면 사용할 수 있습니다.
- 기존 `Assets/FBX/Player/player.fbx`는 뼈대 없는 모델이므로, 플레이어 프리팹의 외형을 `CHA A`로 교체했습니다.

## 적용 방식

- `walk A`의 유효한 걷기 클립을 사용합니다. 비어 있는 `Plane...Action` 클립은 사용하지 않습니다.
- 두 파일의 최상위 뼈대 경로 차이를 보정하여, `walk A`의 애니메이션 커브가 `CHA A`의 `Armature` 아래 뼈대를 움직이도록 연결했습니다.
- 생성된 클립과 Animator Controller는 `Assets/Animation/Player`에 있습니다.
- 플레이어 이동 상태와 실제 수평 속도를 기준으로 걷기를 반복 재생합니다. 정지·공격·피격·사망·UI 열림 중에는 걷기를 멈춥니다.
- 정지 자세는 걷기 첫 프레임을 사용합니다. 별도의 Idle 애니메이션이 생기면 교체할 수 있습니다.
- Root Motion은 끄고 실제 이동은 기존 Rigidbody 이동 코드를 사용합니다.
- 이전에 몬스터에 적용한 플레이어 모델 및 애니메이션 연결은 제거했습니다.

## 팀원에게 전달할 내용

> `CHA A.fbx`에 플레이어 메시·뼈대·스킨이 포함되어 있어서 현재 에셋으로 걷기를 적용했습니다. 추가 리깅 모델은 필요하지 않습니다.
>
> 앞으로 Idle·공격 등 애니메이션을 추가할 때는 이 모델과 뼈대 이름·계층·기준 자세를 동일하게 유지해 주세요. 최상위 Armature 구조도 통일하면 연결하기 편합니다. 이동 애니메이션은 제자리에서 자연스럽게 반복되도록 부탁드립니다.

원본 FBX 경로는 기존 참조를 고려해 유지했습니다. `Monster` 폴더에 있다는 이유로 `CHA A`를 몬스터용으로 사용하지 않도록 주의해 주세요.
